# AI 예상문제 점검표

AI가 만든 예상문제를 붙여 넣으면 문제 유형, 예상 난이도, 학교 기출과의 차이를 보여 주는 웹 도구입니다. MOCKGAP 연구(AI 예상문제로 공부할 때 생기는 과신)에서 학생에게 보여 주는 "기출 비교 성적표"와 "다시 요청하기"를 따로 떼어 낸 것입니다.

- 점검표: https://phaduche.github.io/ai-mock-check/
- 기출로 기준 만들기: https://phaduche.github.io/ai-mock-check/baseline.html
- 실험 진행 페이지: https://github.com/Phaduche/mockgap-study

붙여 넣은 문항은 브라우저 안에서만 처리하고 어디로도 보내지 않습니다. 서버가 없습니다.

## 화면 순서

1. **문제 붙여 넣기:** AI 앱에서 받은 답을 정답·해설까지 통째로 붙여 넣습니다.
2. **기출과 비교:** 문제 유형, 예상 난이도, <보기> 합답형, 자료 해석·계산의 비율을 기출과 막대 두 줄로 나란히 보여 줍니다. 기출과 닮은 정도(%)와 가장 크게 부족한 점 세 가지를 문장으로 띄웁니다.
3. **문항별 결과:** 문항마다 유형, 예상 난이도, 그렇게 판단한 근거, 정답 유무를 보여 줍니다. 기준에 학교 문항분석표 정답률이 있으면 같은 유형의 기출 평균 정답률도 보여 줍니다.
4. **다시 요청하기:** 기출 비율에 맞춘 요청 문장을 만들어 줍니다. 새로 받은 답으로 다시 점검하면 닮은 정도가 어떻게 바뀌었는지 기록이 쌓입니다.
5. **풀어 보기:** 세트를 직접 풀고 유형별 정답률을 봅니다. 닮은 정도가 낮으면 "이 점수로 시험 점수를 짐작하면 안 된다"고 알려 줍니다.

## 분류 규칙 (`classify.js`)

학습하지 않는 규칙입니다. AI 문제와 기출에 **같은 규칙**을 써야 비교가 공정하므로, 기준을 만들 때도 분류를 손으로 바꾸지 않습니다.

| 특징 | 알아보는 표시 |
| --- | --- |
| <보기> 합답형 | 발문에 &lt;보기&gt;와 "ㄱ." 진술이 있음, 또는 선지가 모두 "ㄱ, ㄴ" 조합 |
| 자료 해석 | 표, 그래프, 그림, 자료, 실험 결과, (가)·(나) |
| 계산 | 단위가 붙은 숫자(g, mL, J, % …), "구하시오", "몇 mL" 등 |
| 탐구 설계 | 설계, 실험 방법, 탐구 과정, 변인 |

| 유형 | 조건 | 예상 난이도 |
| --- | --- | --- |
| 서술형 | 서술형 문항 | 자료·계산·설계가 있으면 상, 아니면 중 |
| 응용 | 탐구 설계, 또는 자료+계산, 또는 합답형+(자료 또는 계산) | 상 |
| 개념 활용 | 자료 해석 또는 계산 하나 | 합답형이면 상, 아니면 중 |
| 개념 체크 | 위 표시가 없음 | 합답형이면 중, 아니면 하 |

- **닮은 정도:** 비교 항목마다 두 비율 분포의 총변동거리(0~1)를 구하고, (1 − 평균 거리) × 100으로 나타냅니다.
- **부족한 점 문장:** 기출보다 10%p 넘게 적은 칸만, 큰 순서로 최대 세 개를 보여 줍니다.
- **다시 요청 문장:** 객관식 16 + 서술형 4 기준으로 기출 비율을 문항 수로 바꿔 넣습니다.
- 문항 나누기(`parseAI`)는 mockgap-study / session-frame과 같은 규칙입니다. 발문의 줄바꿈을 남기는 것만 다릅니다.

## 기출 기준

- **기본 기준:** `baselines.json`에는 지금 팀 연구 문서의 예비 조사 요약값 두 개(합답형 약 80%, 자료 해석·계산 약 90%, 기출 67문항)만 있습니다. 그래서 웹에서는 이 두 항목만 비교합니다.
- **기준 만들기:** `baseline.html`에 학교 기출을 붙여 넣으면 같은 규칙으로 유형·난이도 비율까지 계산합니다. 문항분석표가 있으면 문항별 정답률을 넣어 유형별·난이도별 평균 정답률도 담습니다.
- **기준 파일에 담기는 것:** 비율과 평균 정답률뿐이고 문항 원문은 담기지 않습니다. 점검표의 "기준 파일" 칸에서 열면 그 브라우저에서만 쓰고, 모두가 쓰게 하려면 `baselines.json` 목록에 추가해 PR로 올립니다.

## 한계

- 유형과 난이도는 문장 속 표시로 정한 추정값입니다. 실제로 몇 명이 맞혔는지가 아닙니다.
- 그림만 있고 글자가 없는 문항, 이미지로 된 기출은 글자로 옮겨야 분류할 수 있습니다.
- 정답이 맞는지는 검사하지 않습니다. 정답이 빠진 문항만 표시합니다.
- 통합과학 문항으로 만든 규칙이라 다른 과목에서는 맞지 않을 수 있습니다.

## 실행과 검사

- 저장소를 받아 `index.html`을 열면 바로 됩니다. 파일을 더블클릭해 열면 `baselines.json` 대신 `app.js` 안의 같은 기본값을 씁니다.
- 규칙 검사: `node tests/classify.test.js` (설치할 것 없음)
- main에 머지하면 GitHub Pages가 다시 배포됩니다.
